## Windows 终端交互验收

使用 `scripts/terminal-smoke.mjs` 在 Windows PTY 中运行构建后的 CLI，连接本地模拟模型。

新版已通过实际本机 SSE 连接复验中文多行输入、命令审批、工具输出、Token/未定价/估算展示、流式取消与正常退出。

- 中文路径和中文输出正常。
- Alt+Enter 插入换行。
- bracketed paste 保留多行；已复验 Windows 的 CR 与 CRLF 混合换行。
- 展示实际 shell、工作目录和完整命令；`y` 成功执行中文输出命令，`n` 返回 denied。
- 助手结束后渲染 Markdown 及代码块。
- 流式响应期间 Ctrl+C 取消，并返回可继续输入的状态。
- `/permissions auto` 切换权限，`/new` 新建会话恢复启动时的 ask 策略。
- `/exit` 正常退出，验收临时项目与会话自动清理。
